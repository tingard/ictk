# @tingard/ictk-core

Part of [ICTK](https://github.com/tingard/ictk) — composable map-marker icons for MapLibre GL and deck.gl.

Framework-agnostic core: the stylesheet, shared types and helpers used by the React and Svelte bindings. You normally don't install this directly — it comes with `@tingard/ictk-react` or `@tingard/ictk-svelte`.

Usage, API and examples: see the [main README](https://github.com/tingard/ictk#readme).
