# @tingard/ictk-svelte

Part of [ICTK](https://github.com/tingard/ictk) — composable map-marker icons for MapLibre GL and deck.gl.

Svelte 5 bindings (snippets and runes; Svelte 4 is not supported). `npm i @tingard/ictk-svelte`, then `import '@tingard/ictk-svelte/style.css'`.

Usage, API and examples: see the [main README](https://github.com/tingard/ictk#readme).
